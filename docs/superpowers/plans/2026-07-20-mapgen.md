# mapgen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `mapgen`, a Rust binary that generates and incrementally updates a mirrored tree of `_map.md` navigation files for a code repository, plus the eval harness that measures whether those maps actually reduce an agent's tokens-to-answer.

**Architecture:** Tree-sitter parses each source file into a symbol table with exact `file:line` anchors. A Claude model receives that symbol table (never raw source) and returns structured JSON containing only prose — it never emits a line number, so anchors cannot be hallucinated. Leaf directories are generated first via the Batch API at Haiku pricing; parent directories are rolled up from their children's already-generated maps rather than from source, making both the initial build and incremental updates cheap.

**Tech Stack:** Rust 2021, `tree-sitter` (Rust/Python/Go/TypeScript grammars), `reqwest` (blocking, rustls), `serde_json`, `sha2`, `ignore`, `clap`, Claude Messages API + Message Batches API over raw HTTP.

## Global Constraints

- Scope of this plan: spec milestones 1–3 only (leaf generation, rollup, eval harness). The `SessionStart` hook, `semmap sync`, and the GitHub Action are separate plans.
- Language support at v1: **TypeScript, Python, Go, Rust**. Any other extension falls back to a filename-and-imports-only map, which is degraded but never wrong.
- **The model never emits a `file:line`.** Tree-sitter produces every anchor; the model writes prose next to anchors the parser already found. Any code path that lets a model-supplied string become a line number is a defect.
- **Fail closed.** On any ambiguity — unparseable model output, hash mismatch, budget exhaustion — retain the previous map or emit nothing. Never emit a map that might be wrong.
- Leaf-directory model: `claude-haiku-4-5` ($1 / $5 per MTok input/output, 200K context).
- Rollup model (top two levels only): `claude-opus-4-8` ($5 / $25 per MTok, 1M context).
- Required HTTP headers on every Anthropic call: `x-api-key: $ANTHROPIC_API_KEY`, `anthropic-version: 2023-06-01`, `content-type: application/json`.
- Structured output uses `output_config.format` with `{"type": "json_schema", "schema": {...}}`. Every object in the schema must set `"additionalProperties": false` and list `"required"`. The schema subset does **not** support `minLength`, `maxLength`, `minimum`, `maximum`, or `multipleOf` — do not use them.
- `output_config.effort` errors on `claude-haiku-4-5`. Set it only on Opus rollup calls.
- **Do not add `cache_control` anywhere.** The minimum cacheable prefix is 4096 tokens on both Haiku 4.5 and Opus 4.8; mapgen prompts are far shorter, so a breakpoint would silently never cache while still costing a write premium.
- Batch API results arrive in **arbitrary order** — always key results by `custom_id`, never by position.
- `max_tokens: 4096` on every mapgen call. Non-streaming is correct here; responses are small and well under SDK timeout risk.

```rust
use anyhow::Result;
use ignore::WalkBuilder;
use std::collections::BTreeMap;
use std::path::Path;

const DEFAULT_IGNORES: &[&str] = &[
    "node_modules",
    "dist",
    "build",
    "target",
    ".venv",
    "venv",
    "__pycache__",
    ".git",
    "vendor",
];

pub const SOURCE_EXTENSIONS: &[&str] = &["rs", "py", "go", "ts", "tsx", "js", "jsx"];

fn is_source_file(name: &str) -> bool {
    match name.rsplit_once('.') {
        Some((_, ext)) => SOURCE_EXTENSIONS.contains(&ext),
        None => false,
    }
}

fn is_ignored_component(name: &str) -> bool {
    DEFAULT_IGNORES.contains(&name)
}

pub fn walk(root: &Path) -> Result<Vec<SourceDir>> {
    let mut files_by_dir: BTreeMap<String, Vec<String>> = BTreeMap::new();

    let walker = WalkBuilder::new(root)
        .hidden(false)
        .git_ignore(true)
        .add_custom_ignore_filename(".semmapignore")
        .build();

    for entry in walker {
        let entry = entry?;
        if !entry.file_type().is_some_and(|t| t.is_file()) {
            continue;
        }
        let rel = entry
            .path()
            .strip_prefix(root)?
            .to_string_lossy()
            .replace('\\', "/");

        if rel.split('/').any(is_ignored_component) {
            continue;
        }
        let (dir, name) = match rel.rsplit_once('/') {
            Some((d, n)) => (d.to_string(), n.to_string()),
            None => (String::new(), rel.clone()),
        };
        if !is_source_file(&name) {
            continue;
        }
        files_by_dir.entry(dir).or_default().push(name);
    }

    // Every ancestor of a source directory is itself a mapped directory.
    let mut all_dirs: BTreeMap<String, Vec<String>> = BTreeMap::new();
    for dir in files_by_dir.keys() {
        let mut current = dir.clone();
        loop {
            all_dirs.entry(current.clone()).or_default();
            match current.rsplit_once('/') {
                Some((parent, _)) => current = parent.to_string(),
                None => {
                    if current.is_empty() {
                        break;
                    }
                    current = String::new();
                }
            }
        }
    }

    // Attach child directory names to each parent.
    let dir_names: Vec<String> = all_dirs.keys().cloned().collect();
    for dir in &dir_names {
        if dir.is_empty() {
            continue;
        }
        let (parent, name) = match dir.rsplit_once('/') {
            Some((p, n)) => (p.to_string(), n.to_string()),
            None => (String::new(), dir.clone()),
        };
        if let Some(subdirs) = all_dirs.get_mut(&parent) {
            subdirs.push(name);
        }
    }

    let mut out: Vec<SourceDir> = all_dirs
        .into_iter()
        .map(|(rel_path, mut subdirs)| {
            subdirs.sort();
            subdirs.dedup();
            let mut files = files_by_dir.get(&rel_path).cloned().unwrap_or_default();
            files.sort();
            SourceDir { rel_path, files, subdirs }
        })
        .collect();

    // Deepest first, so leaves are generated before the parents that summarize them.
    out.sort_by(|a, b| {
        let depth = |p: &str| if p.is_empty() { 0 } else { p.matches('/').count() + 1 };
        depth(&b.rel_path)
            .cmp(&depth(&a.rel_path))
            .then_with(|| a.rel_path.cmp(&b.rel_path))
    });

    Ok(out)
}
```

```rust
use tree_sitter::{Language, Parser, Query, QueryCursor};

const RUST_QUERY: &str = r#"
(function_item name: (identifier) @name) @fn
(struct_item name: (type_identifier) @name) @struct
(enum_item name: (type_identifier) @name) @enum
(trait_item name: (type_identifier) @name) @trait
"#;

const PYTHON_QUERY: &str = r#"
(function_definition name: (identifier) @name) @fn
(class_definition name: (identifier) @name) @class
"#;

const GO_QUERY: &str = r#"
(function_declaration name: (identifier) @name) @fn
(method_declaration name: (field_identifier) @name) @fn
(type_declaration (type_spec name: (type_identifier) @name)) @struct
"#;

const TS_QUERY: &str = r#"
(function_declaration name: (identifier) @name) @fn
(class_declaration name: (type_identifier) @name) @class
(interface_declaration name: (type_identifier) @name) @interface
"#;

fn language_for(file_name: &str) -> Option<(Language, &'static str)> {
    let ext = file_name.rsplit_once('.')?.1;
    match ext {
        "rs" => Some((tree_sitter_rust::language(), RUST_QUERY)),
        "py" => Some((tree_sitter_python::language(), PYTHON_QUERY)),
        "go" => Some((tree_sitter_go::language(), GO_QUERY)),
        "ts" | "js" => Some((tree_sitter_typescript::language_typescript(), TS_QUERY)),
        "tsx" | "jsx" => Some((tree_sitter_typescript::language_tsx(), TS_QUERY)),
        _ => None,
    }
}

fn kind_for(capture_name: &str) -> Option<SymbolKind> {
    match capture_name {
        "fn" => Some(SymbolKind::Function),
        "struct" => Some(SymbolKind::Struct),
        "class" => Some(SymbolKind::Class),
        "enum" => Some(SymbolKind::Enum),
        "trait" => Some(SymbolKind::Trait),
        "interface" => Some(SymbolKind::Interface),
        _ => None,
    }
}

pub fn extract(file_name: &str, source: &str) -> Vec<Symbol> {
    let Some((language, query_src)) = language_for(file_name) else {
        return Vec::new();
    };

    let mut parser = Parser::new();
    if parser.set_language(&language).is_err() {
        return Vec::new();
    }
    let Some(tree) = parser.parse(source, None) else {
        return Vec::new();
    };
    let Ok(query) = Query::new(&language, query_src) else {
        return Vec::new();
    };

    let capture_names = query.capture_names();
    let mut cursor = QueryCursor::new();
    let mut out = Vec::new();

    for m in cursor.matches(&query, tree.root_node(), source.as_bytes()) {
        // Each match has a @name capture (the identifier) and one kind capture
        // (@fn / @struct / ...). The kind capture also carries the definition's
        // start line, which is what we anchor to.
        let mut name: Option<String> = None;
        let mut kind: Option<SymbolKind> = None;
        let mut line: Option<usize> = None;

        for cap in m.captures {
            let cap_name = capture_names[cap.index as usize];
            if cap_name == "name" {
                name = cap
                    .node
                    .utf8_text(source.as_bytes())
                    .ok()
                    .map(|s| s.to_string());
            } else if let Some(k) = kind_for(cap_name) {
                kind = Some(k);
                // tree-sitter rows are 0-indexed; anchors are 1-indexed.
                line = Some(cap.node.start_position().row + 1);
            }
        }

        if let (Some(name), Some(kind), Some(line)) = (name, kind, line) {
            out.push(Symbol {
                name,
                kind,
                file: file_name.to_string(),
                line,
            });
        }
    }

    out.sort_by(|a, b| a.line.cmp(&b.line).then_with(|| a.name.cmp(&b.name)));
    out.dedup();
    out
}
```

```rust
use anyhow::{anyhow, Context, Result};

fn render_anchor(a: &Anchor) -> String {
    format!("{} ({}:{})", a.name, a.file, a.line)
}

fn parse_anchor(s: &str) -> Result<Anchor> {
    let (name, rest) = s
        .split_once(" (")
        .ok_or_else(|| anyhow!("anchor missing ' (': {s}"))?;
    let inner = rest
        .strip_suffix(')')
        .ok_or_else(|| anyhow!("anchor missing ')': {s}"))?;
    let (file, line) = inner
        .rsplit_once(':')
        .ok_or_else(|| anyhow!("anchor missing ':line': {s}"))?;
    Ok(Anchor {
        name: name.trim().to_string(),
        file: file.trim().to_string(),
        line: line.trim().parse().context("anchor line is not a number")?,
    })
}

pub fn render(map: &DirMap) -> String {
    let mut out = String::new();
    out.push_str(&format!("# {}\n", map.path));
    out.push_str(&format!("derived-from: {}\n\n", map.derived_from));
    out.push_str(&format!("What: {}\n", map.what));

    if let Some(entry) = &map.entry {
        out.push_str(&format!("Entry: {}\n", render_anchor(entry)));
    }

    if !map.key_symbols.is_empty() {
        out.push_str("Key symbols:\n");
        for (anchor, desc) in &map.key_symbols {
            out.push_str(&format!("  {}  {}\n", render_anchor(anchor), desc));
        }
    }

    if !map.depends_on.is_empty() {
        let joined: Vec<String> = map
            .depends_on
            .iter()
            .map(|(p, label)| format!("{p} ({label})"))
            .collect();
        out.push_str(&format!("Depends on: {}\n", joined.join(", ")));
    }

    if !map.look_here_for.is_empty() {
        out.push_str(&format!("Look here for: {}\n", map.look_here_for.join(", ")));
    }

    if !map.subdirs.is_empty() {
        let joined: Vec<String> = map
            .subdirs
            .iter()
            .map(|(name, desc)| format!("./{name} ({desc})"))
            .collect();
        out.push_str(&format!("Subdirs: {}\n", joined.join(", ")));
    }

    out.push_str("Hashes:\n");
    for (file, hash) in &map.hashes {
        out.push_str(&format!("  {file} {hash}\n"));
    }

    out
}

fn split_labeled_list(value: &str) -> Vec<(String, String)> {
    // "src/chain (RPC), src/ledger (balances)" -> [("src/chain","RPC"), ...]
    let mut out = Vec::new();
    let mut depth = 0usize;
    let mut current = String::new();
    for ch in value.chars() {
        match ch {
            '(' => {
                depth += 1;
                current.push(ch);
            }
            ')' => {
                depth = depth.saturating_sub(1);
                current.push(ch);
            }
            ',' if depth == 0 => {
                out.push(std::mem::take(&mut current));
            }
            _ => current.push(ch),
        }
    }
    if !current.trim().is_empty() {
        out.push(current);
    }

    out.into_iter()
        .filter_map(|item| {
            let item = item.trim();
            let (name, rest) = item.split_once(" (")?;
            let desc = rest.strip_suffix(')')?;
            Some((name.trim().to_string(), desc.trim().to_string()))
        })
        .collect()
}

pub fn parse(text: &str) -> Result<DirMap> {
    let mut map = DirMap::default();
    let mut section: Option<&'static str> = None;
    let mut saw_header = false;

    for line in text.lines() {
        // Indented lines belong to the section opened by the last unindented header.
        if line.starts_with("  ") {
            let body = line.trim();
            match section {
                Some("key_symbols") => {
                    let (anchor_part, desc) = body
                        .split_once(")  ")
                        .ok_or_else(|| anyhow!("key symbol line missing ')  ' separator: {body}"))?;
                    let anchor = parse_anchor(&format!("{anchor_part})"))?;
                    map.key_symbols.push((anchor, desc.trim().to_string()));
                }
                Some("hashes") => {
                    let (file, hash) = body
                        .split_once(' ')
                        .ok_or_else(|| anyhow!("hash line missing space: {body}"))?;
                    map.hashes.insert(file.to_string(), hash.trim().to_string());
                }
                _ => return Err(anyhow!("indented line outside a section: {body}")),
            }
            continue;
        }

        let line = line.trim_end();
        if line.is_empty() {
            continue;
        }

        if let Some(path) = line.strip_prefix("# ") {
            map.path = path.trim().to_string();
            saw_header = true;
            section = None;
        } else if let Some(sha) = line.strip_prefix("derived-from: ") {
            map.derived_from = sha.trim().to_string();
            section = None;
        } else if let Some(what) = line.strip_prefix("What: ") {
            map.what = what.trim().to_string();
            section = None;
        } else if let Some(entry) = line.strip_prefix("Entry: ") {
            map.entry = Some(parse_anchor(entry.trim())?);
            section = None;
        } else if line == "Key symbols:" {
            section = Some("key_symbols");
        } else if line == "Hashes:" {
            section = Some("hashes");
        } else if let Some(deps) = line.strip_prefix("Depends on: ") {
            map.depends_on = split_labeled_list(deps);
            section = None;
        } else if let Some(look) = line.strip_prefix("Look here for: ") {
            map.look_here_for = look.split(',').map(|s| s.trim().to_string()).collect();
            section = None;
        } else if let Some(subs) = line.strip_prefix("Subdirs: ") {
            map.subdirs = split_labeled_list(subs)
                .into_iter()
                .map(|(name, desc)| (name.trim_start_matches("./").to_string(), desc))
                .collect();
            section = None;
        } else {
            return Err(anyhow!("unrecognized line in map file: {line}"));
        }
    }

    if !saw_header {
        return Err(anyhow!("map file has no '# <path>' header"));
    }
    Ok(map)
}
```

```rust
fn check_one(anchor: &Anchor, symbols: &[Symbol]) -> Option<AnchorViolation> {
    let by_name: Vec<&Symbol> = symbols.iter().filter(|s| s.name == anchor.name).collect();

    if by_name.is_empty() {
        return Some(AnchorViolation {
            anchor: anchor.clone(),
            reason: format!("no symbol named `{}` in this directory", anchor.name),
        });
    }
    let in_file: Vec<&&Symbol> = by_name.iter().filter(|s| s.file == anchor.file).collect();
    if in_file.is_empty() {
        return Some(AnchorViolation {
            anchor: anchor.clone(),
            reason: format!("symbol `{}` is not in file `{}`", anchor.name, anchor.file),
        });
    }
    if !in_file.iter().any(|s| s.line == anchor.line) {
        return Some(AnchorViolation {
            anchor: anchor.clone(),
            reason: format!(
                "symbol `{}` is at line {} in `{}`, not line {}",
                anchor.name,
                in_file[0].line,
                anchor.file,
                anchor.line
            ),
        });
    }
    None
}

pub fn validate(map: &DirMap, symbols: &[Symbol]) -> Vec<AnchorViolation> {
    let mut out = Vec::new();
    if let Some(entry) = &map.entry {
        if let Some(v) = check_one(entry, symbols) {
            out.push(v);
        }
    }
    for (anchor, _) in &map.key_symbols {
        if let Some(v) = check_one(anchor, symbols) {
            out.push(v);
        }
    }
```

```rust
use sha2::{Digest, Sha256};

pub fn hash_content(content: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(content.as_bytes());
    let digest = hasher.finalize();
    digest.iter().take(8).map(|b| format!("{b:02x}")).collect()
}

pub fn hash_dir(files: &BTreeMap<String, String>) -> BTreeMap<String, String> {
    files
        .iter()
        .map(|(name, content)| (name.clone(), hash_content(content)))
        .collect()
}

pub fn freshness(map: &DirMap, current: &BTreeMap<String, String>) -> Freshness {
    let mut changed = Vec::new();

    for (file, recorded) in &map.hashes {
        match current.get(file) {
            Some(now) if now == recorded => {}
            Some(_) => changed.push(file.clone()),
            None => changed.push(file.clone()),
        }
    }
    for file in current.keys() {
        if !map.hashes.contains_key(file) {
            changed.push(file.clone());
        }
    }

    changed.sort();
    changed.dedup();
    if changed.is_empty() {
        Freshness::Fresh
    } else {
        Freshness::Stale(changed)
    }
}
```

```rust
/// Resolve a model-supplied symbol name to a parser-produced anchor.
/// Returns None when the name does not appear in the symbol table, which is
/// how a hallucinated name is prevented from ever reaching a map file.
fn resolve(name: &str, symbols: &[Symbol]) -> Option<Anchor> {
    symbols.iter().find(|s| s.name == name).map(|s| Anchor {
        name: s.name.clone(),
        file: s.file.clone(),
        line: s.line,
    })
}

pub fn assemble(
    dir_path: &str,
    derived_from: &str,
    symbols: &[Symbol],
    file_contents: &BTreeMap<String, String>,
    response: &DescribeResponse,
) -> DirMap {
    let entry = response
        .entry_symbol
        .as_deref()
        .and_then(|name| resolve(name, symbols));

    let key_symbols = response
        .key_symbols
        .iter()
        .filter_map(|(name, desc)| resolve(name, symbols).map(|a| (a, desc.clone())))
        .collect();

    let subdirs = response
        .subdir_notes
        .iter()
        .map(|(name, note)| (name.clone(), note.clone()))
        .collect();

    DirMap {
        path: dir_path.to_string(),
        derived_from: derived_from.to_string(),
        what: response.what.clone(),
        entry,
        key_symbols,
        depends_on: Vec::new(),
        look_here_for: response.look_here_for.clone(),
        subdirs,
        hashes: hash_dir(file_contents),
    }
}

pub fn request_for(
    custom_id: &str,
    dir_path: &str,
    symbols: &[Symbol],
    file_names: &[String],
    child_summaries: &[(String, String)],
) -> DescribeRequest {
    let mut symbol_names: Vec<String> = symbols.iter().map(|s| s.name.clone()).collect();
    symbol_names.sort();
    symbol_names.dedup();

    DescribeRequest {
        custom_id: custom_id.to_string(),
        dir_path: dir_path.to_string(),
        symbol_names,
        file_names: file_names.to_vec(),
        child_summaries: child_summaries.to_vec(),
    }
}
```

```rust
pub fn build_prompt(req: &DescribeRequest) -> String {
    let mut p = String::new();
    p.push_str(

         navigate the repository without reading every file.\n\n",
    );
    p.push_str(&format!("Directory: {}\n\n", req.dir_path));

    p.push_str("Files in this directory:\n");
    for f in &req.file_names {

    }

    for s in &req.symbol_names {
        p.push_str(&format!("  {s}\n"));
    }

    if !req.child_summaries.is_empty() {
        p.push_str("\nSubdirectories and what each one does:\n");
        for (name, summary) in &req.child_summaries {
            p.push_str(&format!("  {name}: {summary}\n"));
        }
    }

    p.push_str(
        "\nRules:\n\
         - Use only symbol names from the list above, copied exactly. Never invent a name.\n\
         - Never write a file path or a line number. Those are added automatically.\n\
         - `what` is one or two sentences on this directory's responsibility.\n\
         - `key_symbols` is the handful worth knowing, not everything.\n\
         - `look_here_for` is the query terms that should route a reader here.\n",
    );

pub fn build_message_body(model: &str, effort: Option<&str>, prompt: &str) -> Value {
    let mut output_config = json!({
        "format": {
            "type": "json_schema",
            "schema": output_schema()
        }
    });
    // `effort` is rejected on claude-haiku-4-5, so it is set only when supplied.
    if let Some(e) = effort {
        output_config["effort"] = json!(e);
    }

    json!({

        "max_tokens": 4096,
        "output_config": output_config,
        "messages": [{ "role": "user", "content": prompt }]
    })
}

pub fn build_batch_body(model: &str, effort: Option<&str>, reqs: &[DescribeRequest]) -> Value {

                "params": build_message_body(model, effort, &build_prompt(r))
            })
        })
        .collect();
    json!({ "requests": requests })

pub fn parse_model_json(custom_id: &str, text: &str) -> Result<DescribeResponse> {
    let v: Value = serde_json::from_str(text)
        .with_context(|| format!("model output for {custom_id} was not valid JSON"))?;

    let what = v["what"]
        .as_str()
        .ok_or_else(|| anyhow!("missing `what` for {custom_id}"))?
        .to_string();

    let key_symbols = v["key_symbols"]
        .as_array()
        .unwrap_or(&Vec::new())
        .iter()
        .filter_map(|item| {
            Some((
                item["name"].as_str()?.to_string(),
                item["description"].as_str()?.to_string(),
            ))
        })
        .collect();

    let look_here_for = v["look_here_for"]
        .as_array()
        .unwrap_or(&Vec::new())
        .iter()
        .filter_map(|s| s.as_str().map(|s| s.to_string()))
        .collect();

    let subdir_notes = v["subdir_notes"]
        .as_array()
        .unwrap_or(&Vec::new())

        .filter_map(|item| {
            Some((

                item["note"].as_str()?.to_string(),
            ))
        })

        custom_id: custom_id.to_string(),
        what,
        entry_symbol,
        key_symbols,
        look_here_for,
        subdir_notes,
    })
}
```

```rust
const ANTHROPIC_VERSION: &str = "2023-06-01";

impl HttpLlm {
    fn client(&self) -> Result<reqwest::blocking::Client> {
        Ok(reqwest::blocking::Client::builder()
            .timeout(std::time::Duration::from_secs(600))
            .build()?)
    }

    fn headers(&self) -> reqwest::header::HeaderMap {
        let mut h = reqwest::header::HeaderMap::new();
        h.insert("x-api-key", self.api_key.parse().unwrap());
        h.insert("anthropic-version", ANTHROPIC_VERSION.parse().unwrap());
        h.insert("content-type", "application/json".parse().unwrap());
        h
    }

    fn describe_one_by_one(&self, reqs: Vec<DescribeRequest>) -> Result<Vec<DescribeResponse>> {
        let client = self.client()?;
        let mut out = Vec::new();

        for req in reqs {
            let body = build_message_body(
                &self.model,
                self.effort.as_deref(),
                &build_prompt(&req),
            );
            let resp: Value = client
                .post(format!("{API_BASE}/v1/messages"))
                .headers(self.headers())
                .json(&body)
                .send()?
                .error_for_status()?
                .json()?;

            // With output_config.format set, the first text block is the JSON payload.
            let text = resp["content"]
                .as_array()
                .and_then(|blocks| blocks.iter().find(|b| b["type"] == "text"))
                .and_then(|b| b["text"].as_str())
                .ok_or_else(|| anyhow!("no text block in response for {}", req.custom_id))?;

            // Fail closed: a directory whose output we cannot parse is skipped,
            // leaving its previous map in place, rather than emitting a guess.
            match parse_model_json(&req.custom_id, text) {
                Ok(parsed) => out.push(parsed),
                Err(e) => eprintln!("warn: dropping {}: {e:#}", req.custom_id),
            }
        }
        Ok(out)
    }

    fn describe_batched(&self, reqs: Vec<DescribeRequest>) -> Result<Vec<DescribeResponse>> {
        let client = self.client()?;
        let body = build_batch_body(&self.model, self.effort.as_deref(), &reqs);

        let created: Value = client
            .post(format!("{API_BASE}/v1/messages/batches"))
            .headers(self.headers())
            .json(&body)
            .send()?
            .error_for_status()?
            .json()?;

        let batch_id = created["id"]
            .as_str()
            .ok_or_else(|| anyhow!("batch create returned no id"))?
            .to_string();
        eprintln!("batch {batch_id} submitted ({} requests)", reqs.len());

        loop {
            let status: Value = client
                .get(format!("{API_BASE}/v1/messages/batches/{batch_id}"))
                .headers(self.headers())
                .send()?
                .error_for_status()?
                .json()?;

            if status["processing_status"] == "ended" {
                break;
            }
            std::thread::sleep(std::time::Duration::from_secs(30));
        }

        let results_text = client
            .get(format!("{API_BASE}/v1/messages/batches/{batch_id}/results"))
            .headers(self.headers())
            .send()?
            .error_for_status()?
            .text()?;

        let mut out = Vec::new();
        // Results are JSONL and arrive in arbitrary order — key by custom_id.
        for line in results_text.lines().filter(|l| !l.trim().is_empty()) {
            let v: Value = serde_json::from_str(line)?;

                eprintln!("warn: batch entry {custom_id} did not succeed, skipping");
                continue;
            }
            let Some(text) = v["result"]["message"]["content"]
                .as_array()
                .and_then(|blocks| blocks.iter().find(|b| b["type"] == "text"))
                .and_then(|b| b["text"].as_str())
            else {
                eprintln!("warn: batch entry {custom_id} had no text block, skipping");
                continue;
            };
            match parse_model_json(&custom_id, text) {
                Ok(parsed) => out.push(parsed),
                Err(e) => eprintln!("warn: dropping {custom_id}: {e:#}"),
            }
        }
        Ok(out)
    }
}

    fn describe(&self, reqs: Vec<DescribeRequest>) -> Result<Vec<DescribeResponse>> {
        if reqs.is_empty() {
            return Ok(Vec::new());
        }
        if self.use_batch {
            self.describe_batched(reqs)
        } else {
            self.describe_one_by_one(reqs)
        }
```

```rust
use crate::generate::{assemble, request_for};
use crate::hash::{freshness, hash_dir, Freshness};
use crate::map::render;
use crate::parse::extract;
use crate::walk::walk;
use std::fs;

fn read_dir_contents(dir: &Path, files: &[String]) -> BTreeMap<String, String> {
    let mut out = BTreeMap::new();
    for name in files {
        if let Ok(text) = fs::read_to_string(dir.join(name)) {
            out.insert(name.clone(), text);
        }
    }
    out
}

pub fn run(
    root: &Path,
    out_dir: &Path,
    derived_from: &str,
    llm: &dyn Llm,
    existing: &BTreeMap<String, DirMap>,
) -> Result<(BTreeMap<String, DirMap>, RunStats)> {
    // walk() returns deepest-first, so a directory's children are always
    // finished before the directory itself is described.
    let dirs = walk(root)?;
    let mut finished: BTreeMap<String, DirMap> = BTreeMap::new();
    let mut regenerated: std::collections::BTreeSet<String> = Default::default();
    let mut stats = RunStats::default();

    for dir in &dirs {
        let abs = root.join(&dir.rel_path);
        let contents = read_dir_contents(&abs, &dir.files);
        let current_hashes = hash_dir(&contents);

        let child_path = |name: &str| {
            if dir.rel_path.is_empty() {
                name.to_string()
            } else {
                format!("{}/{}", dir.rel_path, name)
            }
        };

        // A parent embeds its children's summaries, so a regenerated child makes
        // its ancestors stale even when their own files are untouched.
        let child_changed = dir
            .subdirs
            .iter()
            .any(|name| regenerated.contains(&child_path(name)));

        // Content-hash short-circuit: an unchanged directory with unchanged
        // children keeps its map and costs nothing. This is what makes
        // incremental runs nearly free.
        if let Some(prev) = existing.get(&dir.rel_path) {
            if !child_changed && freshness(prev, &current_hashes) == Freshness::Fresh {
                finished.insert(dir.rel_path.clone(), prev.clone());
                stats.skipped_unchanged += 1;
                continue;
            }
        }

        let mut symbols = Vec::new();
        for (name, text) in &contents {
            symbols.extend(extract(name, text));
        }

        // Parents summarize children's maps, never children's source.
        let child_summaries: Vec<(String, String)> = dir
            .subdirs
            .iter()
            .filter_map(|name| {
                finished
                    .get(&child_path(name))
                    .map(|m| (name.clone(), m.what.clone()))
            })
            .collect();

        let custom_id = if dir.rel_path.is_empty() {
            "root".to_string()
        } else {
            dir.rel_path.replace('/', "__")
        };

        let request = request_for(&custom_id, &dir.rel_path, &symbols, &dir.files, &child_summaries);
        let responses = llm.describe(vec![request])?;

        let Some(response) = responses.into_iter().find(|r| r.custom_id == custom_id) else {
            // Fail closed: no usable response means no map for this directory.
            stats.dropped += 1;
            continue;
        };

        let map = assemble(&dir.rel_path, derived_from, &symbols, &contents, &response);

        let dest = out_dir.join(&dir.rel_path);
        fs::create_dir_all(&dest)?;
        fs::write(dest.join("_map.md"), render(&map))?;

        finished.insert(dir.rel_path.clone(), map);
        regenerated.insert(dir.rel_path.clone());
        stats.generated += 1;
    }

    Ok((finished, stats))
}
```

```rust
/// Load any maps already present in the output tree so unchanged directories
/// can be skipped instead of regenerated.
fn load_existing(out: &PathBuf) -> BTreeMap<String, semmap::map::DirMap> {
    let mut found = BTreeMap::new();
    let walker = ignore::WalkBuilder::new(out).hidden(false).build();
    for entry in walker.flatten() {
        if entry.file_name() != "_map.md" {
            continue;
        }
        let Ok(text) = std::fs::read_to_string(entry.path()) else {
            continue;
        };
        if let Ok(map) = parse_map(&text) {
            found.insert(map.path.clone(), map);
        }
    }
    found
}

    let api_key = std::env::var("ANTHROPIC_API_KEY")

        api_key,
        model: args.model.clone(),
        effort: args.effort.clone(),
        use_batch: args.batch,

    println!(

        maps.len()
    );
    if stats.dropped > 0 {

    }
```

```rust
fn score_answer(q: &Question, answer: &str) -> bool {
    let hay = answer.to_lowercase();
    q.expect_substrings
        .iter()
        .all(|needle| hay.contains(&needle.to_lowercase()))
}

fn summarize(with_map: &[Score], without_map: &[Score]) -> String {
    let acc = |s: &[Score]| s.iter().filter(|x| x.correct).count();
    let tokens = |s: &[Score]| -> u64 {
        s.iter().map(|x| x.input_tokens + x.output_tokens).sum()
    };

    let with_tokens = tokens(with_map);
    let without_tokens = tokens(without_map);

    let delta_pct = if without_tokens == 0 {
        0.0
    } else {
        (without_tokens as f64 - with_tokens as f64) / without_tokens as f64 * 100.0
    };

    let direction = if delta_pct >= 0.0 {
        format!("{delta_pct:.0}% fewer tokens with the map")
    } else {
        format!("{:.0}% MORE tokens with the map", delta_pct.abs())
    };

    format!(
        "accuracy with map:    {}/{}\n\
         accuracy without map: {}/{}\n\
         tokens with map:      {with_tokens}\n\
         tokens without map:   {without_tokens}\n\
         result:               {direction}\n",
        acc(with_map),
        with_map.len(),
        acc(without_map),
        without_map.len(),
    )
}
```

```rust
/// Concatenate every `_map.md` in the tree. This is the context an agent gets
/// in the with-map arm; the without-map arm gets a bare file listing instead.
fn collect_maps(dir: &PathBuf) -> Result<String> {
    let mut out = String::new();
    for entry in ignore::WalkBuilder::new(dir).hidden(false).build().flatten() {
        if entry.file_name() == "_map.md" {
            out.push_str(&std::fs::read_to_string(entry.path())?);
            out.push('\n');
        }
    }
    Ok(out)
}

fn collect_file_listing(repo: &PathBuf) -> Result<String> {
    let mut out = String::new();
    for entry in ignore::WalkBuilder::new(repo).hidden(false).build().flatten() {
        if entry.file_type().is_some_and(|t| t.is_file()) {
            let rel = entry.path().strip_prefix(repo).unwrap_or(entry.path());
            out.push_str(&rel.to_string_lossy());
            out.push('\n');
        }
    }
    Ok(out)
}

/// Returns the score (with `correct` left false for the caller to fill in,
/// since only the caller holds the question) alongside the answer text.
fn ask(api_key: &str, model: &str, context: &str, question: &str) -> Result<(Score, String)> {
    let client = reqwest::blocking::Client::new();
    let prompt = format!(
        "Answer using only the context below. Name the specific file and symbol.\n\n\
         CONTEXT:\n{context}\n\nQUESTION: {question}"
    );

    let resp: Value = client
        .post("https://api.anthropic.com/v1/messages")
        .header("x-api-key", api_key)
        .header("anthropic-version", "2023-06-01")
        .header("content-type", "application/json")
        .json(&json!({
            "model": model,
            "max_tokens": 1024,
            "messages": [{ "role": "user", "content": prompt }]
        }))
        .send()?
        .error_for_status()?
        .json()?;

    let text = resp["content"]
        .as_array()
        .and_then(|b| b.iter().find(|x| x["type"] == "text"))
        .and_then(|x| x["text"].as_str())
        .ok_or_else(|| anyhow!("no text block in eval response"))?
        .to_string();

    Ok((
        Score {
            correct: false,
            input_tokens: resp["usage"]["input_tokens"].as_u64().unwrap_or(0),
            output_tokens: resp["usage"]["output_tokens"].as_u64().unwrap_or(0),
        },
        text,
    ))
}

fn main() -> Result<()> {
    let args = Args::parse();
    let api_key = std::env::var("ANTHROPIC_API_KEY").context("ANTHROPIC_API_KEY is not set")?;

    let questions: Vec<Question> =
        serde_json::from_str(&std::fs::read_to_string(&args.questions)?)?;

    let map_context = collect_maps(&args.maps)?;
    let listing_context = collect_file_listing(&args.repo)?;

    let mut with_map = Vec::new();
    let mut without_map = Vec::new();

    for q in &questions {
        let (mut s, answer) = ask(&api_key, &args.model, &map_context, &q.question)?;
        s.correct = score_answer(q, &answer);
        println!("[with map]    {} correct={}", q.id, s.correct);
        with_map.push(s);

        let (mut s, answer) = ask(&api_key, &args.model, &listing_context, &q.question)?;
        s.correct = score_answer(q, &answer);
        println!("[without map] {} correct={}", q.id, s.correct);
        without_map.push(s);
    }

    print!("\n{}", summarize(&with_map, &without_map));
    Ok(())
}
```

## Cost model

Recorded here so the CI budget in the spec's error-handling table can be set from real numbers rather than guesses.

| Path | Model | Rate (input / output per MTok) | Applies to |
|---|---|---|---|
| Leaf directories | `claude-haiku-4-5` | $1.00 / $5.00 | The large majority of calls |
| Top two levels | `claude-opus-4-8` | $5.00 / $25.00 | A handful of rollups per repo |
| `--batch` | either | **50% off both** | Full-repo builds; adds minutes of latency |

Because prompts carry only symbol names and file names — never source — a leaf request is on the order of a few hundred input tokens and a few hundred output tokens. A full build of a 500-directory repository at Haiku batch rates lands in the low tens of cents.

An incremental run regenerates each touched directory **plus its ancestor chain up to the root**, because a parent embeds its children's summaries. A PR touching three files in two directories of a five-deep tree therefore regenerates on the order of eight maps, not two — still trivial, but size the CI budget against depth, not just the number of changed files.

Do not add prompt caching to reduce this further: the 4096-token minimum cacheable prefix is far above these prompt sizes, so a breakpoint would charge a write premium and never yield a read.
